## Что такое контроль версий?

Контроль версий — это система, которая записывает изменения в файлах, позволяя вернуться к любой предыдущей версии. Это особенно важно при разработке программного обеспечения, когда над проектом работает несколько человек.

## Git

Git — это распределённая система контроля версий, созданная Линусом Торвальдсом в 2005 году. Основные преимущества Git: распределённость (каждый разработчик имеет полную копию репозитория), скорость (большинство операций выполняются локально) и удобное ветвление.

## Основные команды

git init — инициализация репозитория. git clone — клонирование удалённого репозитория. git add — добавление файлов в индекс. git commit — фиксация изменений. git push — отправка изменений на удалённый сервер. git pull — получение изменений с удалённого сервера.

## GitHub

GitHub — это платформа для хостинга Git-репозиториев. Она позволяет хранить код в облаке, совместно работать над проектами и автоматизировать развёртывание через GitHub Actions.
