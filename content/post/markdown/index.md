Markdown — это легковесный язык разметки, который позволяет форматировать текст с помощью простых символов.

## Основные элементы

Заголовки создаются с помощью символа решётки. Одна решётка — заголовок первого уровня, две — второго и так далее.

Для выделения текста используются звёздочки: одна пара для *курсива*, две пары для **жирного** текста.

Списки бывают нумерованные и маркированные. Маркированные создаются с помощью дефиса или звёздочки в начале строки.

## Ссылки и изображения

Ссылки оформляются так: текст в квадратных скобках, URL в круглых. Изображения — аналогично, но с восклицательным знаком в начале.

## Код

Для вставки кода используются обратные кавычки. Одна пара — для строчного кода, тройная — для блоков кода с подсветкой синтаксиса.

## Где используется

Markdown широко применяется на GitHub, в документации, блогах и статических генераторах сайтов, таких как Hugo.
